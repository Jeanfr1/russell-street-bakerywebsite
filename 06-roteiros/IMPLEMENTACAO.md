# Roteiro para construir o site

1. Identificar a stack e as instruções do repositório de destino. Implementar no projeto autorizado, sem criar uma segunda aplicação desnecessária. Este kit não é uma publicação.
2. Importar a logo e os masters, mantendo as fontes fotográficas intactas. Incluir os WOFFs e sua licença. Criar tokens a partir de `DIRECAO.md`.
3. Montar navegação e hero com texto HTML. Não colocar `hero-desktop.jpg` como página única; a foto de fundo e os PNGs são os assets funcionais.
4. Adaptar `motionAt()` e as máscaras CSS à stack. Reutilizar a biblioteca de animação já existente se suficiente; o estudo usa JavaScript nativo. Limpar listeners e requestAnimationFrame no ciclo de vida do componente.
5. Construir a seleção filtrável e as demais seções com fotos reais. O texto é `CONTEUDO-EN.md`, e os dados são `dados.json`. A seleção não é estoque ao vivo.
6. Usar Instagram e mapa reais. Não inventar telefone, e-mail, entregas, checkout, pedidos, mesas ou disponibilidade.
7. Verificar os recortes das capturas sem mostrar botões/avatares da rede social. `proveniencia-fotos.json` e os estilos do estudo definem as áreas úteis.
8. Revisar inglês em todos os estados, navegação, alt, foco, filtros, contagem acessível, movimento reduzido e telas de 320/390/430 px, tablet, notebook baixo e desktop largo.
9. Executar os checks do repositório, revisar em navegador real e entregar preview com relatório das alterações. Publicar somente no fluxo autorizado.
